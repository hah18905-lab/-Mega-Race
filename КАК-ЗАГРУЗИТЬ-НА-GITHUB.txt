КАК ЗАГРУЗИТЬ ЭТО НА GITHUB
===========================

В архиве лежит папка mega-race — это готовое содержимое репозитория.
Ничего переименовывать и править не нужно, просто загрузите как есть.


ШАГ 1. Создайте репозиторий
---------------------------
Откройте github.com/new

  Repository name   mega-race
  Description       Гонка с трансформирующимся транспортом на C++ и raylib
  Public / Private  на ваш выбор

ВАЖНО: галочки "Add a README file", "Add .gitignore" и "Choose a license"
НЕ ставьте — все эти файлы уже есть в архиве.

Нажмите Create repository.


ШАГ 2. Загрузите файлы
----------------------
После создания откроется страница с подсказками. Нажмите ссылку
"uploading an existing file" (в середине страницы, синим).

Если такой ссылки нет, нажмите Add file -> Upload files.

Теперь самое важное:

  ЗАЙДИТЕ ВНУТРЬ папки mega-race, выделите всё внутри (Ctrl+A)
  и перетащите в окно браузера.

  НЕ перетаскивайте саму папку mega-race целиком.

Почему: если перетащить папку, всё окажется внутри подпапки, и GitHub
не покажет описание на главной странице репозитория.

Правильно выделить и перетащить:
  .gitignore
  CHANGELOG.md
  CMakeLists.txt
  CMakePresets.json
  LICENSE
  README.md
  ROADMAP.md
  assets        (папку целиком)
  build.bat
  docs          (папку целиком)
  main.cpp
  music         (папку целиком)

Подождите, пока все файлы догрузятся (внизу будет список),
затем нажмите зелёную кнопку Commit changes.


ШАГ 3. Проверьте
----------------
Обновите страницу репозитория. Вы должны увидеть:

  - описание игры с таблицами и скриншотами прямо на главной странице
  - список файлов сверху
  - справа надпись MIT license

Если скриншоты не отображаются — значит папка docs не загрузилась,
загрузите её отдельно через Add file -> Upload files.


ШАГ 4. Мелочи по желанию
------------------------
1. В файле LICENSE замените "Ай Тыгор" на то имя, которое хотите указать
   как автора. Прямо на GitHub: откройте файл -> карандашик -> правьте ->
   Commit changes.

2. Справа от названия репозитория нажмите шестерёнку возле слова About
   и добавьте теги (Topics): cpp, raylib, game, racing, gamedev.
   По ним вас найдут другие разработчики.

3. Чтобы выложить готовый к игре архив: справа Releases -> Create a new release.
   Tag version: v4. Release title: MEGA RACE v4. В поле описания можно вставить
   кусок из CHANGELOG.md. Снизу прикрепите zip с игрой.


ЕСЛИ ЧТО-ТО ПОЙДЁТ НЕ ТАК
-------------------------
Пришлите скриншот страницы — подскажу, что нажать.
